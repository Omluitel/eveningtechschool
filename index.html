Syllabus · Lab-based

Build it, don't just watch it

Every module is a hands-on build in your own lab, from the first install to the final project.

Module 01

Home Lab Setup

Start with the hardware you'll support, then build your own lab.

  • Explore what's inside a PC and a server, and how a computer starts up
  • Install VMware Workstation Pro
  • Clean install of Windows 11 in a virtual machine
  • Create local users on a standalone machine

Module 02

Network Troubleshooting

See how an office network fits together and fix it when it breaks.

  • Map the office network: IP addressing, DHCP and DNS
  • Use diagnostic commands and an IP scanner
  • Connect your virtual machines with hypervisor networking

Module 03

Windows Server 2025 Build

Stand up your first server.

  • Configure hypervisor networking for the server
  • Build Windows Server 2025
  • Server housekeeping and virtual networking in action

Module 04

Active Directory From Scratch

Create the directory your whole lab will run on.

  • Install the AD DS role, promote the server and create a forest
  • Create organizational units, users and groups
  • Enable the Recycle Bin and learn admin tips and tricks

Module 05

Domain Join & Group Policy

Bring devices into the domain and control them at scale.

  • Prepare a Windows 11 device and join it to the domain
  • Sign in as a domain user
  • Deploy a corporate wallpaper with Group Policy
  • Configure account lockout and password policies

Module 06

File Server & Shares

Publish shared files and make them recoverable.

  • Mount a disk and create a file share
  • Map network drives manually and with Group Policy
  • Enable access-based enumeration
  • Turn on Shadow Copy for self-service file recovery

Module 07

Print Server

Set up printing the way an office expects it to work.

  • Map printers directly for users
  • Add and manage printers centrally
  • Deploy printers with Group Policy and item-level targeting

Module 08

Microsoft 365 Tenant

Start a tenant and make it yours.

  • Start a Microsoft 365 Business Standard trial
  • Buy a domain and onboard it to your tenant
  • Create users and assign licenses
  • Optional: connect on-premises AD with Entra Connect, hybrid identity and custom UPN

Module 09

Exchange Online & Mail Flow

Manage mail the way a service desk does.

  • Set up user mailboxes and Outlook
  • Create shared mailboxes and manage delegation
  • Build a distribution list
  • Convert a mailbox to shared, enable archiving and litigation hold

Module 10

Intune & Endpoint Management

Enrol and manage devices without touching them.

  • Prepare Autopilot: upload hardware hashes by USB and online, and tag device groups
  • Run Autopilot end to end
  • Use remote actions and compliance policies
  • Deploy apps: Company Portal, Microsoft Store, MSI line-of-business and Win32 packages
  • Push a configuration profile

Module 11

Remote Management & Backup

Monitor your devices and protect your data.

  • Deploy an RMM agent and explore remote monitoring and management
  • Onboard a backup tool to your Microsoft 365 tenant
  • Back up and restore data

Module 12

Service Desk Skills

Learn how a service desk runs day to day.

  • Walk through a ticketing system
  • Work ticket types and manage priority

Module 13

Ticket Simulations

Put it all to work: solve real help desk tickets end to end, from the engineer's seat.

  • Account and access requests
  • Mailbox and Microsoft 365 issues
  • Workstation, printer and network problems
  • Backup and restore requests

Module 14

Career Launch

Get ready to apply for your first IT support role.

  • Resume & ATS
  • Resume review
  • Career coaching
  • Mock interviews
